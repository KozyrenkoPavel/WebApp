# Тестовое задание: клиенты и сделки (Next.js + PostgreSQL)

## Быстрый запуск (ничего устанавливать не нужно)

```
copy .env.example .env
npm install
npm run dev
```

http://localhost:3000, вход: **admin / admin123** (нужен Node.js 20+).

Приложение использует встроенный PostgreSQL (PGlite, работает внутри Node.js)
и сразу содержит демо-данные. Данные хранятся в памяти и сбрасываются при перезапуске сервера.

## Расположение модулей

- `src/lib/db.ts` — подключение: встроенный PostgreSQL
- `src/app/api/*` — REST API (Route Handlers): авторизация, клиенты, сделки
- `src/middleware.ts` — защита страниц и API (JWT в httpOnly-cookie)
- `src/lib/validation.ts` — zod-схемы, общие для формы и API
- `src/components/DataTable.tsx` — таблица: сортировка, пагинация, скрытие колонок
- `src/components/*View.tsx` — справочник и реестр (фильтры, CRUD)

## Требования ТЗ

- Аутентификация: логин/пароль, bcrypt, JWT в cookie
- Drop-down меню: навигация и меню пользователя
- Клиенты: поиск по name и code. Сделки: обязательный период дат («жёсткий» селектор), фильтры по number и client
- Валидация и обязательные поля: zod + пометка `*`, ошибки под полями
- Пагинация, сортировка, фильтрация — на сервере (SQL); скрытие колонок — на клиенте
